# 电环 · BatteryHalo

仿 `myfinder-device-battery` 的思路自研的 Windows 设备电量面板：不按型号硬匹配，而是识别设备当前的连接方式（**有线 USB / 2.4G 接收器 / 蓝牙**）并读取电量。

- 单文件绿色程序，无需安装：`电环.exe`
- 托盘常驻，关闭窗口只是收进托盘，托盘右键可退出
- 每 2 秒刷新一次；设备休眠时回落显示上次读数

## 使用

1. 双击桌面「电环」快捷方式（或 `E:\电环\电环.exe`）
2. 窗口可用标题区域拖动，滚轮可滚动设备列表
3. 右上角三枚按钮：**设置**（齿轮）、**收起为小条**（⌄）、**收进托盘**（×）；刷新仍由程序每 2 秒自动完成
4. 点右上角 × 只是**收进托盘**（后台继续刷新）；想再打开时，**再双击一次快捷方式**即可唤回同一个窗口（单实例，不会新开进程）
5. 彻底退出：托盘图标右键 →「退出」

开机自启默认关闭，现在统一在设置窗口的「系统」里控制，会在
`%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup` 建立快捷方式。

## 连接方式识别规则

| 判据 | 结果 |
| --- | --- |
| 产品名含 RECEIVER / Dongle / 2.4G / 接收器 | 2.4G |
| 蓝牙设备节点（`BTHLE\DEV_*` / `BTHENUM\DEV_*`） | 蓝牙 |
| 其余 USB HID 鼠标 / 键盘 | 有线 |

同一台设备若同时存在多条链路（例如键盘既有 2.4G 接收器又有蓝牙），会自动合并成一张卡片：
主连接按 **有线 > 2.4G > 蓝牙** 选取（插着线就是当前链路），其余链路以
「接收器在线 / 蓝牙在线」标注，卡片名沿用型号名。

## 界面

无边框圆角浮窗，默认主题色渐变，也可切为纯色；主面板与设置页同步。

- **标题行**：`设备电量` + 灰色小字「N 台」；右上角依次为 **设置 / 收起为小条 / 收进托盘**。
- **设备卡**：左侧类型图标、中间「型号 + 状态行」、右侧电量环。状态行以连接方式色点开头（有线蓝 / 2.4G 绿 / 蓝牙紫），后接「休眠中」等说明（休眠时回落到缓存读数），可在设置里关闭。
- **电量环**：默认主题色；低于 20% 固定深红，充电时环内显示黄色闪电并带脉冲光晕，休眠或只有缓存读数时显示灰环。
- **骨架屏**：首次扫描期间显示带扫光动画的占位卡，标题旁显示「正在读取」；收起为小条时显示 mini 骨架。
- **点击穿透**：设置页「系统 → 点击穿透」开启后主面板不再接收鼠标，点击直接落到下方窗口，适合把面板压在别的窗口上或当桌面摆件；要关回来从托盘右键进设置。
- **右键菜单**：同样使用主题皮肤（深色渐变、圆角、阴影分层，不再弹系统浅色菜单）；面板右键「展开 / 收起 · 设置 · 退出」，托盘右键「打开面板 / 设置 / 退出」。

## 设置界面

独立无边框浮窗，顶部 **外观 / 显示 / 系统** 三个标签页，一次只显示一页；实时预览固定在顶部。没有保存 / 取消按钮，调整即时生效并写入 `设置.ini`。

- **外观**：背景（纯色 / 渐变）、字体（粗宋 / 楷书 / 粗黑 / 清晰）、圆角（直角 / 小 / 标准 / 大）、界面大小（小 / 标准 / 大）、面板位置（自由 + 六个贴边位）、设备拖动排序；主题色 9 档：雾蓝（默认）、樱粉、薄荷、鸢尾、赤霞、琥珀、霜雪、墨眉、自定义双色。
- **显示**：连接方式开关、面板关闭 / 收起 / 展开三态、贴边自动直角、实时预览开关、拖动排序、主面板不透明度（30%–100%，10% 一档共 8 档）。
- **系统**：开机自启、默认音频设备切换、AirPods 入耳控制、忽略名单、自动刷新电量时间（关 / 10 / 15 / 30 / 60 分钟）、点击穿透（主面板鼠标穿透，操作落到下方窗口）、任务栏电量（通知区左侧按设备显示图标与百分比，默认开启）。
- **实时预览**：按主面板顺序列出全部设备（最多 4 台，超出显示总数），切主题色或开关时即时更新。
- **其他**：拖动标题区保持缓存背景不闪烁，`Esc` 关闭；设备行右键可「忽略此设备」（写入 `忽略设备.txt`）；蓝牙耳机电量读不到时，鼠标移到电量数字会显示刷新图标，点击主动读取（音频可能中断 1-2 秒）。

## Apple 设备状态

随包附带 `AirPodsHelper.exe`（需要 .NET Framework 4.8），通过 Windows BLE 广播解析 Apple Continuity Proximity Pairing 数据：

- 显示 AirPods / Beats 的左右耳、充电盒电量，以及充电、双耳入耳、盒盖状态。
- 设置页 AirPods 主行用与其他设备同尺寸的 L / R 两个独立电量环显示左右耳（L/R 在环内、电量在环右侧），充电仓作为下一级设备单独一行、单独电量环显示；主面板只显示紧凑的 `L80% · R70%`，不再显示充电盒百分比，也不显示入耳或充电中字样。
- 设置页「系统 → AirPods 入耳控制」可在双耳入耳/取出时自动播放/暂停媒体。
- 设置页设备行右键 AirPods 可选择「播放/暂停媒体」。
- Apple 广播不提供降噪模式控制，AirPodsDesktop 也没有该能力；本程序同样不伪造降噪控制。
旧版设置文件没有 `version`，读取时会按旧档位自动上移一档，保留大小选择但实际尺寸更大。

## 视觉细节

- **电量数字**：跟随所选字体；百分比绘制使用 `NoClip` 和加宽文字框，宋体 / 粗黑等宽字形下也不会裁掉百分号。
- **同心圆角**：分段控件外轨半径 9 / 选中块半径 6（3px 内边距），开关外轨 11 / 滑块 9，菜单外框 12 / hover 8，四角都保持圆润；右键菜单文字水平居中，hover 块向内收，避免与菜单外框圆角发生颜色重叠；菜单贴在主面板右下外侧弹出，不遮挡面板。
- **平衡标题换行**：`BalancedLines` 会在需要两行时选择左右长度最接近的断点，避免最后一行只剩一个孤词。
- **阴影代替边框**：预览卡、主面板设备卡、分段选中块和右键菜单都去掉了 1px 描边，改用多层柔和阴影和填充区分层级。窗口四角不使用封边描边，避免出现颜色重叠。
- **不透明度**：主面板整体按设置值 30%–100% 调透明，10% 一档共 8 档；设置页滑轨可拖动、也可直接点刻度，拖动时实时预览，松手写入 `设置.ini`。窗口低于 100% 时走分层窗口（`WS_EX_LAYERED`）合成，不是自绘的假透明，背景图与渐变一起变淡。

## 托盘电量

- 鼠标悬停托盘图标会列出每台设备当前电量：`设备电量 / ROG Harpe II Ace 44% / VGN V98 Pro 89%`
- 托盘图标本身是一个电池条：按**最低电量**设备填充比例（使用当前主题色），无读数时画一条灰横线
- **任务栏电量**：在任务栏通知区域左侧按设备排列类型图标与电量百分比，颜色跟随主题色；默认开启，托盘右键「任务栏电量」或设置页「系统 → 任务栏电量」可开关，无在线设备时自动隐藏。

## 重新编译

双击 `build.bat` 即可。它调用同目录的 `build.ps1`，使用系统自带
`C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe` 编译（.NET Framework 4.0，C# 5 语法），
无需安装任何 SDK。编译前请先退出正在运行的程序，否则 exe 被占用无法覆盖。

> 说明：批处理仅作 ASCII 启动器，中文路径与参数全部由 PowerShell 脚本处理，
> 避免 cmd 代码页导致中文路径乱码。

AirPodsHelper 是独立的 .NET Framework 4.8 / WinRT 进程，主程序构建不会自动重编它。
修改 `源程序\AirPodsHelper.cs` 后，用下面任一方式重建：

```powershell
# 只重建辅助进程（优先 Windows SDK，缺失时自动使用系统 WinMetadata）
.\build-helper.ps1
# 或显式指定 winmd
.\build-helper.ps1 -Winmd 'C:\Program Files (x86)\Windows Kits\10\UnionMetadata\...\Windows.winmd'

# 同时重建主程序和辅助进程
.\build.ps1 -WithAirPodsHelper
```

`build-helper.ps1` 会自动在 Windows Kits 的 `UnionMetadata` / `References` 目录里查找
`Windows.winmd`，并引用系统的 `System.Runtime.WindowsRuntime.dll` 编译。
