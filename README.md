# 电环 · BatteryHalo

仿 `myfinder-device-battery` 的思路自研的 Windows 设备电量面板：不按型号硬匹配，而是识别设备当前的连接方式（**有线 USB / 2.4G 接收器 / 蓝牙**）并读取电量。

- 单文件绿色程序，无需安装：`电环.exe`
- 托盘常驻，关闭窗口只是收进托盘，托盘右键可退出
- 每 2 秒刷新一次；设备休眠时回落显示上次读数

## 使用

1. 双击桌面「电环」快捷方式（或 `E:\电环\电环.exe`）
2. 窗口可用标题区域拖动，滚轮可滚动设备列表
3. 右上角三枚按钮：**设置**（齿轮）、**收起为小条**（⌄）、**收进托盘**（×）；刷新仍由程序每 2 秒自动完成
4. 点右上角 × 只是**收进托盘**（后台继续刷新）；想再打开时，**再双击一次快捷方式**即可唤回同一个窗口（单实例，不会新开进程）
5. 彻底退出：托盘图标右键 →「退出」

开机自启默认关闭，现在统一在设置窗口的「系统」里控制，会在
`%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup` 建立快捷方式。

## 连接方式识别规则

| 判据 | 结果 |
| --- | --- |
| 产品名含 RECEIVER / Dongle / 2.4G / 接收器 | 2.4G |
| 命中已知 VID:PID 表（含 VGN 有线 320F:5055、dongle 320F:5088、ROG 接收器 0B05:1AD0） | 按表 |
| 蓝牙设备节点（`BTHLE\DEV_*` / `BTHENUM\DEV_*`） | 蓝牙 |
| 其余 USB HID 鼠标 / 键盘 | 有线 |

同一台设备若同时存在多条链路（例如键盘既有 2.4G 接收器又有蓝牙），会自动合并成一张卡片：
主连接按 **有线 > 2.4G > 蓝牙** 选取（插着线就是当前链路），其余链路以
「接收器在线 / 蓝牙在线」标注，卡片名沿用型号名。

## 界面

无边框圆角浮窗，提供两种背景，默认 **渐变**：

- **纯色**：不透明深色底，颜色随主题色轻微着色
- **渐变**：主题色从上到下的深色渐变，顶部略亮、底部收暗；设置页与主面板同步

- **标题行**：`设备电量` + 灰色小字「N 台」；右上角依次为 **设置齿轮 / 收起 / 收进托盘**
- **设备卡**：左侧类型图标，中间「型号 + 一行状态」，右侧环形电量
  - 状态行以一个**连接方式色点**开头：有线蓝、2.4G 绿、蓝牙紫，后面跟「休眠中 · 上次 HH:mm / 另一链路在线」
  - 充电时不显示文字「充电中」，改为在右侧**电量圆环内部**显示黄色闪电，并带脉冲光晕动画
  - 状态行内容可在设置里关闭「连接方式」；电压不再显示
  - 电量环默认使用主题色；电量低于 20% 时固定使用深红色（与主题红色区分），充电时仍优先显示金色；休眠或只有缓存读数时显示灰环，并用状态行的「休眠中 / 上次 HH:mm」说明数据来源
- **骨架屏**：启动后首次扫描期间显示两张带扫光动画的占位卡，标题旁显示「正在读取」；收起为小条时显示两条 mini 骨架，不再先闪一下「未发现设备」
- 右键菜单精简为：面板右键「展开 / 收起 · 设置 · 退出」，托盘右键「打开面板 / 设置 / 退出」；刷新仍自动进行，收起状态下可从右键直接展开
- **右键菜单也换成主题皮肤**：深色渐变、圆角、主题色 hover；去掉硬边框，用阴影和填充区分层级，不再弹系统浅色菜单

## 设置界面

设置窗口是独立无边框浮窗，改为顶部 **外观 / 显示 / 系统** 三个标签页，一次只显示一页，避免窗口超出屏幕；实时预览始终保留在顶部：
标签统一左对齐、所有控件统一右对齐到同一条边线，组与组之间用更大留白和编号标题拉开层次。
**没有保存 / 取消按钮，也没有底部四按钮**：所有调整即时作用到主面板并自动写入 `设置.ini`。

- **外观**
  - 背景：纯色 / 渐变两档；设置页和主面板都立即切换，颜色跟随主题色
  - 字体：粗宋（默认）/ 楷书（系统楷体）/ 粗黑 / 清晰（思源黑 Medium）四档，切换只影响文字，不改固定控件位置；楷书自动加大 1px，电量数字跟随所选字体
  - 圆角：直角 / 小 / 标准 / 大四档；主面板贴近屏幕任一边缘时，自动取消贴边一侧的圆角
  - 面板位置：自由 / 左上 / 右上 / 顶部 / 右下 / 左下
  - 设备排序：主面板展开时可直接拖动设备卡片调整顺序，顺序保存到 `设备排序.txt`
  - 界面大小：展开 小 1.0 / 标准 1.1 / 大 1.2；收起 小 1.0 / 标准 1.2 / 大 1.4；默认标准
  - 主题色：雾蓝（默认）、樱粉、薄荷、鸢尾、赤霞、琥珀六种预设，另有霜雪、墨眉和自定义双色，共 9 档；实时改变电量环、托盘电池和设置页强调色
  - 面板位置：自由 / 左上 / 右上 / 顶部 / 右下 / 左下，下方说明行显示完整位置名
- **显示**
  - 显示连接方式：关掉后状态行不再显示「有线 / 2.4G / 蓝牙」，左侧色点也一并隐藏
  - 面板状态：文字分段「收起 / 展开」，直接切换主面板状态，并与右键菜单双向同步
  - 贴边自动直角：靠近屏幕边缘时自动取消贴边一侧的圆角
  - 实时预览开关：开启时只显示实时连接设备；关闭时显示全部连接过设备，标题同步变化
  - 拖动排序：开启后可在实时预览或展开主面板中拖动已连接设备排序；关闭后禁止拖动，充电仓随主设备整体移动
- **系统**
  - 开机自启：设置窗口内即时切换
  - 音频设备：切换 Windows 默认输出设备（扬声器 / 耳机）和输入设备（麦克风）
- **顶部实时预览**
  - 按主面板的顺序列出**全部设备**（最多展示 4 台，超出时显示总数），不是只显示第一台
  - 两台及以上时逐行排列，设备名、连接状态、电量环与实际设备数据同步
  - 切换主题色或两个显示开关时，预览即时变化；扫描中显示迷你骨架行
- **交互**
  - 标题区域可以拖动，但不再显示四向拖动光标
  - 拖动时保持缓存背景，不重新截屏，因此不会闪烁
  - `Esc` 关闭设置窗口；调整已实时生效，不需要额外确认

窗口背景改为纯色 / 渐变两种不透明填充，不使用系统 Acrylic 或实时截图，因此四角不会再被合成层染黑。
渐变颜色由主题色与深色底混合，`GlassStyle.cs` 统一提供纯色、渐变上限和下限颜色。切换分段不做滑动补间，直接吸附到目标项。

字体也做了可读性处理：改用 `AntiAliasGridFit` + 提高文字对比度；
设置页标签 / 说明 / 分段文字整体放大，主面板型号、状态行和电量数字也相应加大。

每次调整会即时写入程序目录下的 `设置.ini`（`version / scale / theme / position / material / font / showVoltage / showMode`），下次启动自动恢复。
主面板和设置页实时预览都只显示当前连接的鼠标 / 键盘 / 耳机，未连接设备、硬盘、手机等非外设都不会出现。蓝牙耳机没有 Windows 电量属性时显示「—」。
设置页预览中右键任意设备可以选择「忽略此设备」，记录写入 `忽略设备.txt`，之后不再显示；设置页「系统 → 忽略名单」可以一键清空恢复。
Windows 设置里能显示但公开 API 读不到的蓝牙耳机电量（如 WH-1000XM5），把鼠标移到设置页设备行电量数字，或主面板数字位置，会显示刷新图标，点击读取。该操作会短暂释放 HFP 通道，音频可能中断 1-2 秒，读取结果会一直保留到下一次刷新或设备断开；自动刷新间隔可在设置页「系统 → 自动刷新电量时间」选择关闭 / 10 / 15 / 30 / 60 分钟，默认 15 分钟。若无法获取，会通过托盘气泡和状态行提示。

## Apple 设备状态

随包附带 `AirPodsHelper.exe`（需要 .NET Framework 4.8），通过 Windows BLE 广播解析 Apple Continuity Proximity Pairing 数据：

- 显示 AirPods / Beats 的左右耳、充电盒电量，以及充电、双耳入耳、盒盖状态。
- 设置页 AirPods 主行用与其他设备同尺寸的 L / R 两个独立电量环显示左右耳（L/R 在环内、电量在环右侧），充电仓作为下一级设备单独一行、单独电量环显示；主面板只显示紧凑的 `L80% · R70%`，不再显示充电盒百分比，也不显示入耳或充电中字样。
- 设置页「系统 → AirPods 入耳控制」可在双耳入耳/取出时自动播放/暂停媒体。
- 设置页设备行右键 AirPods 可选择「播放/暂停媒体」。
- Apple 广播不提供降噪模式控制，AirPodsDesktop 也没有该能力；本程序同样不伪造降噪控制。
旧版设置文件没有 `version`，读取时会按旧档位自动上移一档，保留大小选择但实际尺寸更大。

## 视觉细节

- **电量数字**：跟随所选字体；百分比绘制使用 `NoClip` 和加宽文字框，宋体 / 粗黑等宽字形下也不会裁掉百分号。
- **同心圆角**：分段控件外轨半径 9 / 选中块半径 6（3px 内边距），开关外轨 11 / 滑块 9，菜单外框 12 / hover 8，四角都保持圆润；右键菜单文字水平居中，hover 块向内收，避免与菜单外框圆角发生颜色重叠；菜单贴在主面板右下外侧弹出，不遮挡面板。
- **平衡标题换行**：`BalancedLines` 会在需要两行时选择左右长度最接近的断点，避免最后一行只剩一个孤词。
- **阴影代替边框**：预览卡、主面板设备卡、分段选中块和右键菜单都去掉了 1px 描边，改用多层柔和阴影和填充区分层级。窗口四角不使用封边描边，避免出现颜色重叠。

## 托盘电量

- 鼠标悬停托盘图标会列出每台设备当前电量：`设备电量 / ROG Harpe II Ace 44% / VGN V98 Pro 89%`
- 托盘图标本身是一个电池条：按**最低电量**设备填充比例（使用当前主题色），无读数时画一条灰横线

## 已知边界

- ROG 的**有线 USB（PID 7273）**与**鼠标自身 BLE 通道**尚未实测；按目前的 COM 选择逻辑，有线模式会走旧协议分支，读不到时显示「设备休眠」。
- 只有实现了上述私有协议、或系统侧有蓝牙电量属性的设备才能显示数字；其余设备会出现在列表里但没有读数（显示 `—`）。
- 华硕 Gear Link 若在运行，会同时占用接收器的 `mi_02&col03` 接口。本程序用共享方式（`FILE_SHARE_READ|FILE_SHARE_WRITE`）打开，实测可与 Gear Link 共存。
- 鼠标 / 键盘空闲一段时间会休眠（接收器上报 `connect: disconnect, idle: 1`），此时没有回包，界面显示灰显的「休眠中 · 上次 HH:mm」。

## 重新编译

双击 `build.bat` 即可。它调用同目录的 `build.ps1`，使用系统自带
`C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe` 编译（.NET Framework 4.0，C# 5 语法），
无需安装任何 SDK。编译前请先退出正在运行的程序，否则 exe 被占用无法覆盖。

> 说明：批处理仅作 ASCII 启动器，中文路径与参数全部由 PowerShell 脚本处理，
> 避免 cmd 代码页导致中文路径乱码。

AirPodsHelper 是独立的 .NET Framework 4.8 / WinRT 进程，主程序构建不会自动重编它。
修改 `源程序\AirPodsHelper.cs` 后，用下面任一方式重建：

```powershell
# 只重建辅助进程（优先 Windows SDK，缺失时自动使用系统 WinMetadata）
.\build-helper.ps1
# 或显式指定 winmd
.\build-helper.ps1 -Winmd 'C:\Program Files (x86)\Windows Kits\10\UnionMetadata\...\Windows.winmd'

# 同时重建主程序和辅助进程
.\build.ps1 -WithAirPodsHelper
```

`build-helper.ps1` 会自动在 Windows Kits 的 `UnionMetadata` / `References` 目录里查找
`Windows.winmd`，并引用系统的 `System.Runtime.WindowsRuntime.dll` 编译。
